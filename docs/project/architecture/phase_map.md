# DARE-RUL High-Level Phase Map

- Phase 0: environment, Git and reproducibility setup.
- Phase 1: dataset validation, literature matrix, baseline and evaluation protocol.
- Phase 2: C-MAPSS telemetry producer/consumer, Kafka schema, ordering and throughput.
- Phase 3: Spark Structured Streaming, transformations, checkpointing and HDFS/Parquet storage.
- Phase 4: engine-wise 15-cycle/30-cycle features and degradation signals.
- Phase 5: literature-backed baseline reproduction and fixed-weight ensemble.
- Phase 6: multi-resolution RF/Gradient Boosting experts plus validation-learned reliability/disagreement-aware combiner.
- Phase 7: RMSE/MAE/NASA score where appropriate, ablation, cross-subset robustness, runtime/throughput/latency, resource measurements and explanation stability.
- Phase 8: maintenance priority demonstration, dashboard, final reproducible demo and handover. Research-paper drafting is postponed by project decision.

The candidate adaptive combiner is a research hypothesis. Novelty must be established against the closest prior work; no performance improvement is assumed.
